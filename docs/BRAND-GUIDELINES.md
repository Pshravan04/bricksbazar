# BRICKSBAZAR — Brand Guidelines

## 1. Official Brand Identity
- **Brand Name**: BricksBazar
- **Official Asset**: Original Brand Logo located at `/public/brand/logo.png`
- **Tagline**: India's Premier Real Estate & Construction Marketplace

## 2. Color Palette
- **Primary Brand Red**: `#C6383B`
- **Primary Brand Red Hover**: `#AB2F32`
- **Soft Red / Badge Background**: `#FCEEEF`
- **Subtle Red Tint**: `#FDF5F5`
- **White (Dominant Interface Color)**: `#FFFFFF`
- **Light Background**: `#F8F8F8`
- **Main Text (High Legibility)**: `#252525`
- **Secondary Text**: `#777777`
- **Muted Text**: `#9E9E9E`
- **Border**: `#EAEAEA`
- **Success / Verified**: `#21865B`
- **Warning**: `#D68A2E`
- **Error**: `#C6383B`

## 3. Typography
- **Primary Font**: Plus Jakarta Sans / Manrope
- **Heading Scale**:
  - H1: 36px - 48px, Bold / Extrabold (tight letter spacing `-0.02em`)
  - H2: 28px - 32px, Bold
  - H3: 20px - 24px, SemiBold / Bold
  - Body: 14px - 16px, Regular / Medium
  - Small / Badge: 11px - 12px, Medium / SemiBold

## 4. UI Rules
- White is the dominant canvas color.
- Red is reserved for brand identity, primary CTA buttons, active tabs, selected filter chips, verified highlights, and active links.
- No excessive solid red backgrounds.
- High-contrast, dark typography for effortless reading.
- Crisp, modern thin borders (`#EAEAEA`) with subtle soft shadows (`0 2px 10px rgba(0,0,0,0.04)`).
