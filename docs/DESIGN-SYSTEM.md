# BRICKSBAZAR — Design System Specifications

## 1. Design Principles
- **Clarity & Hierarchy**: Clean, editorial-inspired Indian real estate layouts.
- **Architectural Polish**: High-fidelity imagery, structured metadata pills, clean typography.
- **Trust & Verification**: Clear verification badges, RERA registration numbers, transparent pricing in INR (Crores & Lakhs).
- **Responsive Simplicity**: Desktop multi-column grid with sticky sidebars; full-screen drawers on mobile.

## 2. Core Atoms & Components
- **Buttons**:
  - Primary: `#C6383B` background, white text, 8px rounded, hover `#AB2F32`.
  - Secondary: White background, `#EAEAEA` border, `#252525` text, hover `#F8F8F8`.
  - Outline Red: White background, `#C6383B` border & text, hover `#FCEEEF`.
  - Ghost: Transparent background, hover `#F8F8F8`.
- **Inputs & Selects**:
  - Border: 1px solid `#EAEAEA`, focus ring with brand red subtle accent, 8px border radius.
- **Cards**:
  - White background, 1px `#EAEAEA` border, 12px border radius, subtle hover elevation (`0 12px 30px rgba(0,0,0,0.08)`).
- **Badges**:
  - Verified: Green `#21865B` with soft green background `#E9F5EF`.
  - Featured: Red `#C6383B` with soft red background `#FCEEEF`.
  - Status (Ready to Move / Under Construction): Neutral dark badges.
- **Modals & Drawers**:
  - Centered modal with backdrop blur, 16px radius.
  - Mobile bottom-sheet / right-side drawer with fluid animations.

## 3. Data Representation Tokens
- Indian Currency: Format as `₹ 1.25 Cr`, `₹ 85 L`, or `₹ 45,000 / mo`.
- Area: Format in square feet (`sq.ft`).
- RERA Badges: Display RERA registration IDs on every verified property/project.
