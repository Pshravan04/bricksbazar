# Phase 07: New Projects — Scope

## Objective
Implement dynamic new project discovery and detail experiences (`/new-projects` and `/projects/[slug]`) for BricksBazar. Showcase RERA-approved new launches, under-construction towers, and master planned integrated townships from marquee Indian builders.

## Deliverables
1. Projects Directory (`/new-projects`):
   - Project search by name, developer, or locality.
   - City, developer, status, and budget filters.
   - Sort by relevance, starting price ascending/descending.
   - Project cards with starting price, configurations, RERA approval badge, and developer pedigree.
2. Dynamic Project Detail Page (`/projects/[slug]`):
   - Architectural gallery showcase with full-screen `ImageGallery` modal.
   - RERA compliance badge with registration number.
   - Comprehensive timeline & snapshot metrics (possession date, project acreage, total towers).
   - Detailed project overview, architectural highlights, and lifestyle amenities.
   - Download brochure UI trigger with demo feedback.
   - Direct developer sales advisory desk with sticky enquiry form and VIP site visit booking.
   - Cross-linked similar project recommendations.
