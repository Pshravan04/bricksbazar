# Phase 13: Property Submission Wizard — Scope

## Objective
Provide an end-to-end, RERA-compliant, 14-step property submission wizard that empowers individual property owners, real estate agents, brokers, and builders to post verified residential, commercial, or plot listings on BricksBazar.

## 14-Step Process Breakdown
1. **Purpose**: Outright Sale/Resale vs. Lease/Rent.
2. **Category**: Residential, Commercial, Land / Plot.
3. **Specific Type**: Apartment, Villa, Independent House, Penthouse, Commercial Office, Commercial Shop, Warehouse, Plot / Land.
4. **Location & Address**: Indian metro selection, locality, street address, 6-digit PIN code, landmark.
5. **Project / Society Name**: Gated society, CHSL, or standalone builder project.
6. **BHK & Layout**: Room configuration (1 RK to 5+ BHK, Studio), bathrooms, balconies.
7. **Area Measurements**: Super built-up, RERA carpet area, and built-up area in sq.ft.
8. **Floor & Facing**: Unit floor number, total tower floors, Vastu facing direction, furnishing, and possession status.
9. **Pricing**: Expected total price or monthly rent, security deposit, maintenance fees, negotiation preference, and dynamic calculated rate per sq.ft.
10. **Amenities**: Selection of 16+ amenities (Swimming pool, Gym, 24/7 Security, Elevators, Piped gas, EV charging, Vastu, etc.).
11. **Property Photos**: Photo upload manager with URL previews, caption inputs, cover photo selector, and delete controls.
12. **Description & Highlights**: Headline, detailed description paragraph, and dynamic selling highlight badges.
13. **Contact & RERA Credentials**: Posted by (Owner / Agent / Builder), contact name, 10-digit Indian mobile number, email, and mandatory State RERA number for agents/builders.
14. **Review & Publish**: Comprehensive overview card with quick edit links, terms & accuracy confirmation, and demo submission modal with reference ID.

## Core Features
- Step navigation carousel with forward/backward history and clickable visited steps.
- Real-time step-by-step form validation preventing progression with invalid or missing data.
- LocalStorage draft persistence allowing users to save and resume work at any time.
- Reset / clear draft button for quick testing.
- Simulation modal confirming submission into demo moderation queue with link to agent dashboard.
