# Phase 08: Agents and Brokers — Scope

## Objective
Establish professional directory and profile routing for licensed real estate agents and property brokers across India (`/agents`, `/agents/[slug]`, `/brokers`, `/brokers/[slug]`). Build consultant profile views detailing experience, RERA registration numbers, active inventory counts, micro-market specializations, and direct enquiry channels.

## Deliverables
1. Directory Index Pages (`/agents` & `/brokers`):
   - Location, experience, and verification filters.
   - Text search matching name, agency, or specialization.
   - Professional cards with rating stars, review count, and listing badges.
2. Dynamic Consultant Profile Page (`/agents/[slug]` & `/brokers/[slug]`):
   - High-resolution avatar and verified RERA badge.
   - RERA registration number, languages spoken, and active listing counts.
   - Micro-market specializations chips.
   - Active property listings by the consultant.
   - Sticky contact and lead inquiry widget.
3. Registration Gateway link to `/register?role=agent`.
