# Phase 09: Builders and Developers — Scope

## Objective
Implement builder directory and company profile routing for reputable real estate developers (`/developers` and `/developers/[slug]`). Provide detailed developer track records, completed/ongoing projects statistics, RERA compliance credentials, and corporate sales desks.

## Deliverables
1. Developers Directory (`/developers`):
   - City and minimum experience filters.
   - Text search matching developer name, headquarters, or operating cities.
   - Developer cards displaying ongoing/completed projects and rating stars.
2. Developer Profile View (`/developers/[slug]`):
   - Company branding and founded year.
   - Project delivery statistics (Total, Ongoing, Completed).
   - Regional operating footprint.
   - Active project portfolio grid.
   - Corporate sales desk inquiry form.
